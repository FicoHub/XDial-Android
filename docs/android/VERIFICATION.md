# Android 移植验证报告

## 0.9.1-port.6（2026-10-23）

目标：按确定稿重做全部界面；普通手机保持单栏，Galaxy Z Fold8 内屏等宽屏自动改为两栏。

### 改动

- 布局按可用宽度切换：小于 600dp 单栏，600dp 及以上左右两栏（左：状态、场景、保持常连；右：线路与各设置页）。折叠、展开时就地切换，不重建 Activity，当前页面保留。
- 「保持常连」改为分组列表：进度环 + 一行一项，右侧直接显示「去设置 / 已开启」；长说明移到脚注；检测到「屏蔽未使用 VPN 的连接」时红字提醒。
- 可在手机上添加、修改、删除切换场景用的 Wi-Fi（写入 `match_ssids`），可一键填入当前 Wi-Fi；连接中修改会立即重新判断场景，无需重连。
- 状态卡：琥珀色表示连接中/重连中，浅红表示失败并提供「查看详情」；在公司 Wi-Fi 全部直连时标题为「全部直连」；分流时副标题写明「公司内网走公司 VPN，其余直连」这类规则名。
- 线路卡片右侧由单选圈改为用途标签（默认出口 / 规则名）；场景、默认出口、导入、加密方式改为底部面板（宽屏为居中对话框）；所有确认框统一样式。
- 默认出口选择作用于当前实际运行的场景；诊断页增加当前网络、保持常连状态，可一键复制诊断信息；关于页更新过时说明。

## 0.9.1-port.5（2026-10-23）

目标：像常驻代理一样一直连着，熄屏、换网络、重启、公司 Wi-Fi 都不用手动操作。

### 改动

- 支持系统「始终开启的 VPN」（`SUPPORTS_ALWAYS_ON=true`），服务以 `START_STICKY` 运行并记住「用户希望保持连接」。
- 断线自动重试：网络类错误按 5/10/30/60/120/300 秒退避，网络恢复立即重试；登录失败、证书、配置、授权类错误不重试（避免锁号）。核心报告线路失效时自动重建。
- 开机、App 更新后自动恢复（`BOOT_COMPLETED` / `MY_PACKAGE_REPLACED`），补上系统「始终开启」在更新时可能跳过重启的竞争；周期任务与打开 App 时兜底恢复进程意外退出的情况。
- 按 Wi-Fi 自动切换场景：实现配置里的 `match_ssids`，连上绑定的 Wi-Fi 时运行该场景，离开后回到用户选择的场景；需要位置权限「始终允许」。
- 首页新增「保持常连」检查页（始终开启的 VPN / 电池不限制 / Wi-Fi 自动切换），诊断页显示运行场景与当前 Wi-Fi。
- 忽略信号强度等无关的网络能力变化，避免误重置连接或触发重试风暴。

### 实测（Android 16 模拟器，企业 AnyConnect 真实账号）

| 测试 | 结果 |
|---|---|

## 0.9.1-port.2（2026-10-22）

环境：独立 Android 16 / API 36 Google APIs ARM64 模拟器 `XDial_UI_Test`（Pixel 7 尺寸，serial `emulator-5580`）。工具链在 Mac Studio 上重新安装：Go 1.26.5（官方包，SHA-256 已核对）、Temurin JDK 17、Android SDK platform 36 / build-tools 36.0.0 / NDK 27.1.12297006。Go 核心从源码完整重编。

### 本版改动

- **界面重做**：参考手机「设置」的分组列表。首页为状态卡片 + 连接按钮，依次是「当前场景 / 线路 / 配置 / 更多」。每种线路只显示必要字段，证书、SNI 等收进「高级」。支持深色模式、系统手势栏与刘海屏留白、软键盘不遮挡输入框，并在平板/折叠屏展开时限制内容宽度。
- **AnyConnect 在 Android 上实际不可用的问题已修复**：sslcon 在连接前用 netlink 查询默认路由，Android 10+ 的 SELinux 禁止应用绑定 `netlink_route_socket`，连接在联系服务器前就以 `permission denied` 失败。新增 `vpnc_android.go`，与 iOS 一样把路由/DNS 交给系统 VPN，仅用一次不发包的 UDP connect 取得本机 IPv4 作为客户端标识。上一版只验证了「不可达服务器正确失败」，没有覆盖成功路径。
- 错误提示改为一句可操作的中文，原始错误放在「连接诊断」里，可复制。
- 修改配置或切换场景时不必先断开：保存后可一键重新连接。
- 新增 Shadowsocks / Trojan / VMess / AnyTLS 线路的「测试连接」（复用核心的独立测速会话，不建立 VPN）。
- 导出配置（核心脱敏，不含密码/密钥/UUID）。
- 状态卡片只在内容变化时刷新，界面空闲时不再每 0.5 秒重绘。

|---|---|

| 企业 AnyConnect 全局出口 | 独立测试 App 访问 ipinfo.io，出口 IP 从宿主网络的出口变为企业 VPN 出口 |
| 企业 AnyConnect + 分流规则 | 场景规则绑定 Direct 的目标在 VPN 连接期间直连成功 |
