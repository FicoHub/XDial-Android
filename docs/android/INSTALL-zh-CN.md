# XDial Android 安装与使用

这是基于 XDial v0.9.1 源码制作的 **非官方 Android 测试移植版**。需要 Android 8.0 或更高版本，支持 ARM64、ARMv7 手机。不含 VPN 账号、节点或订阅。

## 安装 / 升级

1. 把 `XDial-Android-<版本>.apk` 下载到手机并打开。
2. 如系统提示，允许浏览器或文件管理器「安装未知应用」。
3. 已装过旧版时直接覆盖安装即可，签名相同，已有配置会保留。

## 三步用起来

1. 在「线路」右边点 **＋ 添加**，顶部选协议类型，只填需要的几项，点底部「保存」。新线路默认成为「默认出口」。
2. 点顶部状态卡片右上角的 **开关**。第一次会弹出 Android 的 VPN 请求，点「确定」；通知权限用于显示连接状态。
3. 卡片变成青色、显示「已连接」即可使用。再点一次开关断开。

- 线路右侧的标签说明它在当前场景里负责什么：「默认出口」，或者某条分流规则的名字（如「公司内网」）。
- 「场景」「默认出口」两块方块：点一下从底部弹出选项切换。
- 修改线路或切换场景时不必先断开：保存后会询问是否立即重新连接。
- 右上角「⋮」：粘贴配置文本、编辑完整配置、关于与开源许可、重置全部配置。

## 保持常连（熄屏、换网络、重启都不用管）

首页「保持常连」里有三项，按提示各开一次即可：

1. **系统「始终开启的 VPN」**：系统 VPN 设置里点 XDial 右边的齿轮打开。不要打开「屏蔽未使用 VPN 的连接」，否则 VPN 断开时手机会完全断网。
2. **电池不限制后台**：避免熄屏后被省电策略关掉。三星手机还要确认 XDial 不在「休眠应用」里。
3. **读取 Wi-Fi 名称**（配置里有 Wi-Fi 绑定时出现）：需要位置权限并选「始终允许」，XDial 只读 Wi-Fi 名称。

同一页下方的「按 Wi-Fi 自动切换场景」列出了哪些 Wi-Fi 会切到哪个场景。点「添加 Wi-Fi」可以加上公司的其他 Wi-Fi（例如 5G 频段），能一键填入当前连着的 Wi-Fi 名称；点已有的一行可以修改或删除。名称必须和手机 Wi-Fi 列表里显示的完全一致。改完立即生效，不用重新连接。

另外内置了：

- 断网、超时、服务器暂时连不上时**自动重试**（5 秒、10 秒、30 秒……最长 5 分钟一次），网络恢复会立刻重试。
- **账号密码错误、证书错误不会重试**，避免把账号锁住，会直接显示原因。
- 手机重启、App 更新后，只要你没有手动断开，会自动连回来；万一进程意外退出，后台最迟约 15 分钟内、或你打开 XDial 时立即恢复。
- 只有你点开关断开、或在系统设置里断开时，才会真正停止。

## 使用公司提供的配置

私有构建已经内置公司默认配置：第一次打开（或从旧版升级、原配置里没有按 Wi-Fi 切换的场景时）会自动载入，并沿用你之前给同一 VPN 服务器填过的用户名和密码；没填过的话，点线路填上即可。用户名或密码为空时不会去登录，会先引导填写。「⋮ → 重置全部配置」会恢复为这份默认配置。

如果需要换成别的 XDial 配置文件（JSON），也可以直接导入，分流规则和场景都已经配好：

1. 首页底部「导入配置 → 从文件选择」，选中配置文件并确认导入。
2. 点导入后的 VPN 线路，填上自己的用户名和密码，保存。配置文件本身不含账号密码。
3. 点「场景」选择要用的场景（例如「公司内网走 VPN、其余直连」的那个），再打开开关。

配置里如果给场景绑定了 Wi-Fi（例如公司 Wi-Fi → 「公司」场景，全部直连），在「保持常连」里授权后会自动切换；离开该 Wi-Fi 回到你选的场景。公司还有别的 Wi-Fi 名称时，在「保持常连」页直接添加即可。

## 折叠屏

- 合上用外屏时，和普通手机一样是单栏。
- 展开后（屏幕宽度 600dp 以上，例如 Galaxy Z Fold8 内屏），自动变成左右两栏：左边是连接状态、场景和开关，右边是线路和各设置页；保存、删除按钮移到右栏顶部，选项改为居中弹窗。
- 展开、合上时不会丢失正在编辑的页面。

## 各类线路要填什么

| 类型 | 必填 | 高级（一般不用动） |
|---|---|---|
| AnyConnect | 地址、用户名、密码 | 跳过证书验证 |
| Shadowsocks | 地址、端口、加密方式、密码 | — |
| Trojan / AnyTLS | 地址、端口、密码 | SNI、跳过证书验证 |
| VMess | 地址、端口、UUID | — |
| Tailscale | 无（出口节点可留空） | MagicDNS |

- **AnyConnect** 地址端口不是 443 时要带上，例如 `vpn.example.com:8443`。它兼容 Cisco AnyConnect 与 ocserv 服务器；山石 Hillstone、深信服等私有协议入口不兼容。如果公司 VPN 同时开了 AnyConnect/ocserv 入口，填那个入口即可。
- Shadowsocks、Trojan、VMess、AnyTLS 线路页有 **测试连接**，不用连接 VPN 就能检查服务器是否可用。
- **Tailscale** 保存后会引导登录一次；之后可在该线路页点「登录 Tailscale」重新登录。

## 场景与分流

- 首页的「场景」「默认出口」两块方块显示当前使用的场景和出口，点一下即可更换。
- 导入的配置如果带分流规则，会显示「分流规则 N 条」：命中规则的流量按规则走，其余走默认出口。
- 分流规则需要在电脑端编辑后导入；手机端只做选择和线路修改，保持简单。

## 配置

- **导入配置**（首页底部）：可选文件或粘贴文本，支持 XDial、Clash、Surge。导入会替换当前全部线路和场景。
- **导出**（首页底部）：导出文件不含密码、密钥和 UUID。
- **⋮ → 编辑完整配置**：直接修改 JSON，保存前会检查，出错不会覆盖原配置。
- 配置经 Android Keystore 加密后存于应用私有目录，系统备份关闭。卸载会删除配置和登录状态。

## 出问题时

- 连接失败时，状态卡片变成浅红色，并用一句话说明原因（如「用户名或密码错误」「连接服务器超时」）。点卡片或底部「诊断」可以看到原始错误，并可一键复制。
- 错误信息可能包含服务器地址，分享前请检查。
- Android 同一时间只能开一个 VPN。连接前请关闭其他 VPN 应用。

## 与 macOS 版的差异

- 沿用原仓库 iOS/tvOS 移动端的 DNS 路径：普通解析默认 `1.1.1.1`，AnyConnect 下发的企业 DNS 与显式启用的 MagicDNS 由原核心处理。
- 本应用自身流量不进入自己建立的 VPN，避免回环；其他应用的 IPv4/IPv6 都进入 VPN。
- 尚未移植：macOS 应用进程规则、无中断场景切换（切换场景会短暂重连）、完整的规则编辑界面。

包名 `dev.xdial.port`；最低 API 26；目标 API 35。版本号见「更多 → 关于」。APK SHA-256 见同目录 `.apk.sha256` 文件。
