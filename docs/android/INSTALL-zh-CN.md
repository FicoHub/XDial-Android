# XDial Android 安装与使用

这是基于 XDial v0.9.1 源码制作的 **非官方 Android 测试移植版**。需要 Android 8.0 或更高版本，支持 ARM64、ARMv7 手机。不含 VPN 账号、节点或订阅。

## 安装

1. 将 `XDial-Android-0.9.1-port.apk` 下载到手机并打开。
2. 如系统提示，允许当前文件管理器或浏览器“安装未知应用”，然后完成安装。
3. 打开 **XDial Android**，点“新建线路与场景”，填写你自己的连接参数；也可导入配置文件或粘贴配置。
4. 选择场景，点“连接当前场景”，同意 Android 的 VPN 请求。通知权限用于显示常驻连接状态。
5. 点“断开连接”结束。修改配置或切换场景时，先断开。

首次默认场景为“直连”，只用于验证网络接入；它不会自动提供远端 VPN。
Android 每个用户仅允许一个 VPN，连接 XDial 会涉及系统的 VPN 切换授权。此版本不支持与另一 Android VPN 同时工作。

## 配置

- **AnyConnect**：服务器、用户名、密码。TLS 证书验证默认开启。
- **Shadowsocks**：服务器、端口、密码；加密方法填在“用户名 / VMess UUID / SS 加密方法”一栏，默认 `aes-128-gcm`。
- **Trojan / AnyTLS**：服务器、端口、密码，可填 SNI。
- **VMess**：服务器、端口、UUID；更复杂传输配置请通过文件或 JSON 导入。
- **Tailscale**：新建线路后会打开登录引导；也可从“使用说明与开源许可 → Tailscale 登录”重新登录。浏览器授权后返回，连接时会先结束登录准备会话。可选 Exit Node IP 与 MagicDNS。Auth Key 不写入配置。
- **分流规则**：导入 XDial Profile / 支持的 sing-box 资源配置 / Clash / Surge，或编辑 Profile JSON；绑定关系由原 Go 核心编译。不是所有第三方配置字段都能迁移，无法支持的内容会报错。

密码配置经 Android Keystore 加密后存于应用私有目录，系统备份关闭。Tailscale 运行身份在同一私有目录。卸载会删除这些数据，除非你另行导出或备份。

## 与 macOS 的差异

- 使用原仓库的 **iOS/tvOS 移动端 DNS 路径**：普通解析默认 `1.1.1.1`，AnyConnect 企业 DNS 与显式启用的 MagicDNS 交给原核心处理。它不等同于 macOS 的 DNSService/按线路解析合同。
- 本应用自身 UID 不进入自己建立的 VPN，避免核心回环。其他应用的 IPv4/IPv6 默认路由进入 TUN。
- macOS 应用进程规则、无中断场景切换、常驻 VPN/开机自启、完整 macOS 配置库 UI 尚未移植。
- 断网时保留 VPN 等待基础网络恢复。系统强杀或主动断开会释放 VPN；本版本没有 always-on 的“无 VPN 禁止联网”保证。
- “已连接”表示核心及 VPN 入口成功启动，不代表所有远端账号、目标服务和两种 IP 地址族都已验证可达。

## 排错

连接失败时查看“连接错误详情”。错误可能含服务器地址，请勿公开含私人信息的截图。检查账号、证书、网络、端口和设备后台限制后，断开再连接。
覆盖升级必须使用相同签名；如果提示签名冲突，不要直接卸载以免丢失配置，请先备份需要的内容。

包名：`dev.xdial.port`；版本：`0.9.1-port.1`；版本号：`90101`；最低 API：26；目标 API：35。
APK SHA-256 见同目录的 `.apk.sha256` 文件。

对应源码及构建方法见 `BUILDING.md`；功能验证范围见随附验证报告。未经真机验证的功能不能视作已在你的手机上验收。

本次 Android 16 模拟器上，核心关闭 TUN 后，系统可能再用约 10 秒撤销 VPN 网络记录。断开后如暂时不能联网，请等待系统 VPN 图标消失；该延迟已纳入隔离环境恢复测试。
